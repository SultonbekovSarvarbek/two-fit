# Обновление сервера

Пошагово, для Ubuntu/Debian. Команды выполняются в папке проекта (там, где лежит `.env`).

## 1. Сделать резервную копию базы

```bash
cp data/two_fit.db data/two_fit.db.bak-$(date +%Y%m%d-%H%M)
```

Новые колонки в базе добавятся сами при запуске, но копия нужна на случай отката.

## 2. Забрать код

```bash
git pull origin main
```

## 3. Установить Tesseract (чтение скриншотов 1Fit)

Программа, которая читает текст со скриншотов, и языки: русский, узбекский (латиница и кириллица), английский.
Приложение 1Fit бывает на любом из них — скриншот, который прислал продавец, был на английском.

```bash
sudo apt update
sudo apt install -y tesseract-ocr tesseract-ocr-eng tesseract-ocr-rus tesseract-ocr-uzb tesseract-ocr-uzb-cyrl
```

Проверить:

```bash
tesseract --version          # должна быть версия 4 или 5
tesseract --list-langs       # в списке должны быть eng, rus, uzb, uzb_cyrl
```

Если Tesseract не поставить, бот работает как раньше — просто не читает скриншоты, их смотрит только администратор.

## 4. Обновить Python-зависимости

Добавились `pytesseract` и `Pillow`.

```bash
source .venv/bin/activate
pip install -r requirements.txt
```

Проверить, что Python видит Tesseract:

```bash
python -c "from two_fit import ocr; print('Tesseract:', 'включён' if ocr.available() else 'НЕ найден')"
```

## 5. Проверить `.env`

Сверьте с `.env.example`. Что поменялось и добавилось:

| Настройка | Значение | Что делает |
|---|---|---|
| `COMMISSION_PERCENT` | `15` | Комиссия за абонемент. **Если в `.env` стоит `10` — поменяйте на `15`** (или удалите строку). Объявления, на которые продавцы уже согласились по 10%, закроются по 10%. |
| `AUTO_PRICE` | `1` | Цена абонемента считается сама по ценам 1Fit и каждую ночь снижается. `0` — продавец вводит цену сам. |
| `SCREENSHOT_REQUIRED` | `1` | Скриншот абонемента обязателен (до 3, видит только администратор). `0` — можно пропустить. |
| `PROMO_ENABLED` | `0` | Продажа промокодов скрыта. `1` — включить. |
| `PROMO_COMMISSION_PERCENT` | `30` | Комиссия за промокод, когда они включены. |

Если строки нет в `.env`, действует значение по умолчанию из таблицы — добавлять не обязательно.

## 6. Перезапустить бота

Как бот запущен у вас, так и перезапустите, например:

```bash
sudo systemctl restart two-fit      # если это служба systemd
```

## 7. Проверить после запуска

В логе (`journalctl -u two-fit -n 50` для systemd) должны быть строки:

- `Two Fit bot started`
- `screenshot reading (Tesseract): on` — если `off`, вернитесь к шагам 3–4
- `repriced N listings` — ночной пересчёт цен отработал при запуске

В Telegram:

1. Откройте Mini App → «Продать»: наверху блок «🔒 Скриншоты абонемента (0/3)» с подсказкой «…заполним сами».
2. Прикрепите скриншот карточки абонемента из 1Fit — поля «Тариф», «Действует до» и «Заморозка» должны
   заполниться сами, внизу появится «Заполнили по скриншоту: …».
3. Отправьте объявление и откройте его в `/admin`: в карточке строка «🔎 Со скриншота: …».

## Если со скриншота читается не то

Включите запись прочитанного текста в лог — добавьте в `.env` строку и перезапустите бота:

```bash
OCR_LOG=1
```

Загрузите скриншот ещё раз и посмотрите лог (`journalctl -u two-fit -n 100`): после строки `screenshot text:` будет
всё, что прочитал Tesseract. Пришлите этот текст — по нему видно, где правило разбора ошиблось.
Потом уберите `OCR_LOG=1`.

## Откат

```bash
git checkout <предыдущий коммит>
cp data/two_fit.db.bak-<дата> data/two_fit.db
sudo systemctl restart two-fit
```
