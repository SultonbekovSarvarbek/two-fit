# Two Fit — Telegram-бот

Обычная доска объявлений (как OLX) для продажи оставшегося срока абонементов 1Fit.
Продавец платит один раз за размещение анкеты (по умолчанию 30 000 сум, Click или Payme прямо в Telegram),
администратор проверяет объявление, а покупатели видят имя, телефон и Telegram продавца и договариваются с ним напрямую.
Two Fit не участвует в сделке, не принимает оплату за абонементы и не связан с 1Fit.
Поддержка — [@s_sarvar](https://t.me/s_sarvar).

> Прежняя модель (оператор согласует сделки, комиссия 15% после продажи, контакты видит только админ)
> сохранена в ветке `commission-model`.

## Что умеет

**Пользователи** (русский / ўзбекча, язык сохраняется):
- **Все абонементы** — каталог одобренных объявлений, фильтр по городу, страницы. Карточка: город, сколько осталось,
  дата окончания, цена (вся сумма, рассрочка 1Fit уже внутри), заморозка, описание и **контакты продавца**:
  имя, телефон и Telegram (кнопка «Написать продавцу в Telegram», если у продавца есть @username).
  Под ними — напоминание не переводить деньги, пока абонемент не переоформлен в 1Fit.
- **Продать абонемент** — те же шаги анкеты, что раньше (город → тариф 1Fit → дата окончания → оплачен полностью или
  рассрочка → заморозка → цена → описание → скриншоты → имя и телефон). Имя и телефон теперь публичные — бот об этом
  говорит прямо. В предпросмотре видно, как объявление увидят покупатели, с контактами.
  Кнопка «💳 Оплатить 30 000 сум и отправить»: анкета сохраняется со статусом «Ждёт оплаты», бот присылает счёт
  Telegram (Click / Payme). После оплаты объявление уходит на модерацию. Закрыл оплату — можно оплатить позже
  в «Мои объявления». Изменять уже оплаченное объявление — бесплатно (оно снова проходит модерацию).
- **Мои объявления** — статусы, «Оплатить», изменить, снять с публикации, «✅ Продано — убрать из каталога».
- **Поддержка** и **Как это работает**.

**Мини-апп** (по желанию) — то же самое в виде приложения: каталог, карточка с кнопками «Написать в Telegram»
и «Позвонить», продажа одной формой (с именем и телефоном), оплата размещения через `openInvoice`,
«Мои объявления» (оплатить, изменить, снять, продано).

**Закрытая админка** (`/admin`, только для ID из `ADMIN_IDS`): модерация (одобрить / одобрить без описания /
отклонить с причиной), объявления по статусам (в том числе «Ждут оплаты»), скриншоты и сверка с ними,
оплачено ли размещение и когда, снятие с публикации, статистика (активные, на модерации, ждут оплаты, продано,
число оплат и сумма). Быстрый поиск: `/l 12`.
`/askprice` — разослать продавцам опубликованных объявлений и объявлений на модерации просьбу обновить цену
(каждому один раз, на его языке, с кнопками на его объявления; перед отправкой бот показывает, скольким уйдёт).

### Правила, которые соблюдает бот
- Пока размещение не оплачено, объявление не видят ни покупатели, ни модерация.
- Перед оплатой бот сверяет счёт: это объявление продавца, оно ждёт оплаты, сумма та же. Один платёж Telegram
  засчитывается один раз (уникальный `telegram_payment_charge_id`), даже если Telegram пришлёт его повторно.
- Оплата один раз за объявление: изменения бесплатные. Снятое с публикации неоплаченное объявление оплату не обходит.
- Имя и телефон обязательны — их видят все покупатели; Telegram берётся из профиля продавца.
- В описании бот по-прежнему не пропускает телефоны, @username и ссылки: контакты показываются отдельно.
- Скриншоты видит только администратор. Бот никогда не спрашивает пароли и коды 1Fit. Работает только в личных сообщениях.

### Рекомендуемая цена и цены 1Fit
- Цену продавец вводит сам и может изменить её в любой момент через «Изменить» (`AUTO_PRICE=0`, по умолчанию).
  На шаге «Цена» (в боте и в мини-аппе) он видит **рекомендуемую цену** и кнопку «Поставить». Расчёт:
  берётся самый короткий тариф 1Fit, который покрывает оставшиеся дни (3, 6, 12 или 24 мес.), его цена
  пересчитывается на эти дни, минус 15%. Если абонемент в рассрочке, оставшиеся платежи, которые покупатель
  внесёт сам, вычитаются из цены. Код — `two_fit/pricing.py` (там же скидка и пределы).
- Дороже 85% от цены 1Fit поставить нельзя — бот объясняет, что у 1Fit выйдет выгоднее; намного дешевле
  (меньше 40%) — можно, но бот предупреждает об ошибке.
- В карточке объявления покупатель видит «≈ 459 000 сум/мес · у 1Fit 658 000 (−15%)».
- **Наблюдатель цен 1Fit** 5 раз в день (`FIT_WATCH_TIMES`, по Ташкенту) читает цены из API 1Fit
  (`FIT_API_URL`, Ташкент) и сравнивает с ценами бота. Если они изменились — администраторам приходит
  сообщение с кнопками «Обновить цены в боте» / «Оставить как есть». Сами цены не меняются: ошибка чтения
  не должна превратиться в странные рекомендации. Если 1Fit не отвечает 2 проверки подряд — одно
  предупреждение в день. Команда `/prices` (и кнопка «💹 Цены 1Fit» в `/admin`) показывает текущие цены,
  последнюю проверку и позволяет проверить сейчас. Выключить — `FIT_WATCH=0`.

## Запуск

Обновление уже работающего сервера — пошагово в [`deploy/UPDATE.md`](deploy/UPDATE.md).

Нужен Python 3.11+.

```bash
git clone https://github.com/SultonbekovSarvarbek/two-fit.git
cd two-fit
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # и заполните BOT_TOKEN и ADMIN_IDS
python -m two_fit
```

Данные хранятся в `data/two_fit.db` (SQLite) и сохраняются после перезапуска — включая незаконченные
шаги анкеты. Для постоянной работы запустите бота как службу (systemd, Docker, PM2 и т. п.)
и делайте резервную копию `data/`.

## Что настроить

1. **Токен** — создайте бота в @BotFather, вставьте токен в `.env` → `BOT_TOKEN`.
2. **Администраторы** — запустите бота, отправьте ему `/id`, впишите полученные ID через запятую
   в `ADMIN_IDS`, перезапустите.
3. **Контакт поддержки** — `SUPPORT_USERNAME` в `.env` (сейчас `s_sarvar`). Меняется в одном месте для всего бота.
4. **Оплата размещения** — в @BotFather: ваш бот → *Payments* → выберите **Click** или **Payme** (в Узбекистане),
   подключите магазин по их инструкции и скопируйте токен провайдера в `.env` → `PAYMENT_PROVIDER_TOKEN`.
   Цена — `LISTING_FEE` (сум, по умолчанию 30000). Без токена оплата выключена и объявления размещаются бесплатно.
   Сначала можно проверить с тестовым токеном (*Connect … Test*) — деньги не списываются.
   **Payme напрямую (с фискальными чеками)** — вместо токена из @BotFather можно подключить кассу Payme Business
   по Merchant API (см. ниже «Payme»). Если заданы `PAYME_MERCHANT_ID` и `PAYME_KEY`, оплата идёт через Payme.
5. **Картинки** — см. [`assets/README.md`](assets/README.md): приветствие 640×360 и логотип.
6. **Описание в BotFather** (по желанию): `/setdescription` и `/setabouttext` — можно взять
   текст приветствия из `two_fit/locales/*.json` → `welcome`.

## Мини-апп

Мини-апп — это страница, которую отдаёт сам бот (отдельно ничего запускать и собирать не нужно).
Telegram открывает мини-аппы только по **HTTPS**, поэтому нужен публичный адрес:

1. Направьте HTTPS-адрес на порт бота (`WEBAPP_PORT`, по умолчанию 8080): через nginx / Caddy на сервере
   или, для пробы, через туннель — например `cloudflared tunnel --url http://localhost:8080`.
2. Впишите адрес в `.env` → `WEBAPP_URL=https://ваш-адрес/` и перезапустите бота.

После этого слева от поля ввода появится кнопка **Two Fit**, а в чате вместо клавиатуры с разделами
останется одна кнопка «Открыть приложение» (её же присылает `/app`). Админка `/admin` работает как раньше.
Чтобы выключить мини-апп, очистите `WEBAPP_URL` и перезапустите бота.

- Вход — по подписи Telegram (`initData`): пароли не нужны, чужие объявления и контакты не видны.
- Скриншот абонемента, прикреплённый в мини-аппе, бот присылает продавцу в чат — так он попадает к администратору.
- Тексты мини-аппа — ключи `app.*` в тех же файлах `two_fit/locales/*.json`.
- Код: `two_fit/webapp/server.py` (API) и `two_fit/webapp/static/index.html` (страница).

## Payme (Merchant API)

Продавец нажимает «💳 Оплатить через Payme» (в боте — кнопка-ссылка, в мини-аппе открывается страница Payme),
платит на сайте Payme, а Payme сам вызывает наш сервер — `POST https://app.twofit.uz/payme` (JSON-RPC,
логин `Paycom`, пароль — ключ кассы). Код — `two_fit/payme.py`, маршрут — в `two_fit/webapp/server.py`.

- **CheckPerformTransaction** — можно ли оплатить: объявление существует, ждёт оплаты, сумма совпадает
  (в тийинах: 30 000 сум = 3 000 000). В ответе — `detail` для фискального чека: название «Размещение объявления №…»,
  цена, количество 1, `code` (МХИК), `package_code`, `vat_percent` из `.env`.
- **CreateTransaction** — Payme заблокировал деньги. Одно объявление — одна открытая транзакция.
- **PerformTransaction** — оплачено: объявление уходит на модерацию, продавцу и администраторам приходит сообщение.
- **CancelTransaction** — отмена. Если оплата уже прошла, деньги возвращаются и объявление снова ждёт оплаты.
- **CheckTransaction**, **GetStatement** — сверка; **ChangePassword** — Payme меняет ключ кассы (сохраняется в базе).
- Транзакция, которую не провели за 12 часов, отменяется (причина 4).

Как подключить:
1. В кабинете Payme Business создайте кассу, укажите адрес `https://app.twofit.uz/payme` и поле счёта `order_id`
   (или своё — тогда `PAYME_ACCOUNT`).
2. Впишите в `.env` `PAYME_MERCHANT_ID`, `PAYME_KEY`, `PAYME_IKPU`, `PAYME_PACKAGE_CODE`, `PAYME_VAT_PERCENT`.
   Для проверки в песочнице — тестовый ключ и `PAYME_TEST=1`, потом рабочий ключ и `PAYME_TEST=0`.
3. Веб-сервер бота должен быть доступен по HTTPS (nginx из `deploy/nginx` уже проксирует все пути, включая `/payme`).
   Он запускается и без мини-аппа, если Payme настроен.

## Как править тексты

Все тексты — в двух файлах: `two_fit/locales/ru.json` и `two_fit/locales/uz.json`
(узбекский — кириллица). Меняйте только значения справа, ключи и `{подстановки}` оставляйте.
После правки запустите тесты — они проверят, что в обоих языках одинаковые ключи и подстановки.
Список городов — `CITIES` в `two_fit/i18n.py` и ключи `city.*` в файлах текстов.

## Тесты

```bash
pip install -r requirements-dev.txt
pytest
```

Тесты без реального токена: проверки ввода, все статусы и запреты, оплата размещения (проверка перед оплатой,
повторный платёж, неоплаченные не видны), «Продано», сквозной сценарий через настоящие обработчики (продавец на
узбекском, покупатель и админ на русском), мини-апп (подпись Telegram, проверки формы, контакты, счёт на оплату,
чужие объявления), закрытый доступ к админке, сохранение данных и анкеты после перезапуска.

  app.py             сборка бота и диспетчера

  money.py           форматирование сумм

## Пока не входит

Автоматическая передача абонементов, интеграция с 1Fit, чат покупатель–продавец внутри бота,
возврат оплаты из бота (делается в кабинете Click / Payme), платное продвижение объявлений.

### Чтение скриншотов 1Fit (Tesseract)

Продавец прикладывает до 3 скриншотов карточки абонемента (видит только администратор). Если на сервере стоит
Tesseract, со скриншотов читаются тариф, дата окончания, дата начала и дни заморозки: в Mini App форма заполняется
сама, в боте продавцу предлагается взять данные со скриншота, а администратор в карточке модерации видит,
что прочитано и что не совпадает с объявлением. Без Tesseract всё работает, просто без чтения.

Установка на сервере и проверка — пошагово в [`deploy/UPDATE.md`](deploy/UPDATE.md):

```bash
sudo apt install -y tesseract-ocr tesseract-ocr-eng tesseract-ocr-rus tesseract-ocr-uzb tesseract-ocr-uzb-cyrl
pip install -r requirements.txt   # pytesseract и Pillow
```
