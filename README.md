# Two Fit — Telegram-бот

Площадка для покупки и продажи оставшегося срока абонементов 1Fit по принципу OLX.
Two Fit — независимая площадка: не выкупает абонементы, не принимает оплату, не связан с 1Fit.
Сделки согласует оператор [@s_sarvar](https://t.me/s_sarvar).

## Что умеет

**Пользователи** (русский / ўзбекча, язык сохраняется):
- **Все абонементы** — каталог одобренных объявлений, новые сверху, фильтр по городу, страницы.
  Карточка: номер, город, тариф, дата окончания, цена, описание. Кнопки «Хочу купить» и «Связаться с оператором».
- **Продать абонемент** — 7 шагов (город → тариф → дата → цена → описание → скриншот → имя и телефон),
  на каждом шаге «Назад» и «Отмена». Перед отправкой — предпросмотр, расчёт комиссии 10%
  и обязательная галочка согласия. Изменение цены сбрасывает согласие.
- **Мои объявления** — статусы, причина отклонения, изменение (с повторной модерацией),
  снятие с публикации, «Сообщить о продаже».
- **Поддержка** и **Как это работает** — переход к @s_sarvar и короткое объяснение.

**Закрытая админка** (`/admin`, только для ID из `ADMIN_IDS`):
модерация (одобрить / одобрить без описания / отклонить с причиной), все объявления по статусам,
контакты продавцов и покупателей, скриншоты, заявки, резерв и снятие резерва, итоговая цена
(при изменении — подтверждение продавца), закрытие сделки, отметка о получении комиссии,
история сделок и статистика. Быстрый поиск: `/l 12`.

### Правила, которые соблюдает бот
- Комиссия 10% с продавца — только после закрытия сделки, от фактической цены. Покупатель комиссию не платит.
- Сделку нельзя закрыть, пока продавец не подтвердил итоговую цену.
- Одно объявление нельзя продать дважды, комиссию нельзя отметить полученной дважды
  (проверяется и в коде, и уникальными ограничениями базы).
- Одна активная заявка покупателя на объявление; своё объявление купить нельзя; заявка не резервирует автоматически.
- В каталоге нет проданных, снятых, зарезервированных, просроченных и неодобренных объявлений.
- Личные данные (имя, телефон, Telegram, скриншоты) видит только администратор. В описании бот не пропускает
  телефоны, @username и ссылки; администратор дополнительно проверяет описание перед публикацией.
- Бот никогда не спрашивает пароли и коды 1Fit. Работает только в личных сообщениях.

## Запуск

Нужен Python 3.11+.

```bash
git clone https://github.com/SultonbekovSarvarbek/two-fit.git
cd two-fit
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # и заполните BOT_TOKEN и ADMIN_IDS
python -m two_fit
```

Данные хранятся в `data/two_fit.db` (SQLite) и сохраняются после перезапуска — включая незаконченные
шаги анкеты. Для постоянной работы запустите бота как службу (systemd, Docker, PM2 и т. п.)
и делайте резервную копию `data/`.

## Что настроить

1. **Токен** — создайте бота в @BotFather, вставьте токен в `.env` → `BOT_TOKEN`.
2. **Администраторы** — запустите бота, отправьте ему `/id`, впишите полученные ID через запятую
   в `ADMIN_IDS`, перезапустите.
3. **Контакт поддержки** — `SUPPORT_USERNAME` в `.env` (сейчас `s_sarvar`). Меняется в одном месте для всего бота.
4. **Картинки** — см. [`assets/README.md`](assets/README.md): приветствие 640×360 и логотип.
5. **Описание в BotFather** (по желанию): `/setdescription` и `/setabouttext` — можно взять
   текст приветствия из `two_fit/locales/*.json` → `welcome`.

## Как править тексты

Все тексты — в двух файлах: `two_fit/locales/ru.json` и `two_fit/locales/uz.json`
(узбекский — кириллица). Меняйте только значения справа, ключи и `{подстановки}` оставляйте.
После правки запустите тесты — они проверят, что в обоих языках одинаковые ключи и подстановки.
Список городов — `CITIES` в `two_fit/i18n.py` и ключи `city.*` в файлах текстов.

## Тесты

```bash
pip install -r requirements-dev.txt
pytest
```

45 тестов без реального токена: расчёт комиссии, проверки ввода, все статусы и запреты,
двойная продажа и двойная комиссия (в том числе одновременные нажатия), сквозной сценарий
через настоящие обработчики (продавец на узбекском, покупатель и админ на русском),
скрытие личных данных, закрытый доступ к админке, сохранение данных и анкеты после перезапуска.

## Структура

```
two_fit/
  __main__.py        запуск: python -m two_fit
  app.py             сборка бота и диспетчера
  config.py          настройки из .env
  repo.py            база SQLite и все бизнес-правила
  money.py           расчёт комиссии
  validators.py      проверка ввода (даты, цены, телефоны, контакты в тексте)
  i18n.py, locales/  тексты RU / UZ
  storage.py         хранение шагов анкет в SQLite
  bot/handlers/      каталог, продажа, мои объявления, покупка, админка
tests/               тесты
assets/              картинки
```

## Пока не входит

Онлайн-оплата, автоматическая передача абонементов, интеграция с 1Fit, чат покупатель–продавец,
встроенный чат поддержки, платное продвижение, автоматическая проверка оплаты.
