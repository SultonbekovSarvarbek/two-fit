# Two Fit — Telegram-бот

Площадка для покупки и продажи оставшегося срока абонементов 1Fit по принципу OLX.
Two Fit — независимая площадка: не выкупает абонементы, не принимает оплату, не связан с 1Fit.
Сделки согласует оператор [@s_sarvar](https://t.me/s_sarvar).

## Что умеет

**Пользователи** (русский / ўзбекча, язык сохраняется):
- **Все абонементы** — каталог одобренных объявлений, новые сверху, фильтр по городу, страницы.
  Карточка: номер, город, сколько осталось («⏳ Осталось: 7 мес.» — вместо названия тарифа, которое путало), дата окончания, цена, описание; если продавец указал дату начала —
  полоска «Использовано 8 из 12 мес. · осталось 4 мес.»; оплачен ли абонемент полностью или в рассрочку
  («дальше покупатель сам платит 500 000 сум/мес × 9»). Кнопки «Хочу купить» и «Связаться с оператором».
- **Продать абонемент или промокод** — промокоды по умолчанию скрыты (`PROMO_ENABLED=1` включает их): тогда сразу продаётся абонемент, а в каталоге нет промокодов. С включёнными — сначала выбор, что продаётся. Промокод 1Fit: 8 шагов (город → что даёт →
  активировать до → сам код → цена → описание → скриншот → имя и телефон), код видят только администратор и продавец,
  покупатель получает его от оператора после оплаты; комиссия 30% (`PROMO_COMMISSION_PERCENT`).
  Абонемент — 10 шагов (город → тариф 1Fit на выбор: 6, 12 или 24 месяца → дата окончания → дата начала (необязательно) →
  оплачен полностью или рассрочка (тогда платёж в месяц и сколько платежей осталось) → остались ли дни заморозки и сколько (покупатель видит «❄️ Заморозка: осталось 20 дн.») → цена (по умолчанию не спрашивается: `AUTO_PRICE=1` ставит рекомендуемую по ценам 1Fit) → описание → скриншот → имя и телефон),
  на каждом шаге «Назад» и «Отмена». Перед отправкой — предпросмотр, расчёт комиссии (15% за абонемент, 30% за промокод)
  и обязательная галочка согласия. Изменение цены сбрасывает согласие.
- **Мои объявления** — статусы, причина отклонения, изменение (с повторной модерацией),
  снятие с публикации, «Сообщить о продаже».
- **Поддержка** и **Как это работает** — переход к @s_sarvar и короткое объяснение.

**Мини-апп** (по желанию, включается одной настройкой) — те же разделы в виде приложения внутри Telegram:
каталог с фильтром по городу, заявка на покупку, продажа одной формой с расчётом комиссии, «Мои объявления»
(изменить, снять, сообщить о продаже), «Как это работает», поддержка и смена языка. Правила те же, что в боте.
Модерация, резерв и подтверждение итоговой цены остаются в чате с ботом.

**Закрытая админка** (`/admin`, только для ID из `ADMIN_IDS`):
модерация (одобрить / одобрить без описания / отклонить с причиной), все объявления по статусам,
контакты продавцов и покупателей, скриншоты, заявки, резерв и снятие резерва, итоговая цена
(при изменении — подтверждение продавца), закрытие сделки, отметка о получении комиссии,
история сделок и статистика. Быстрый поиск: `/l 12`.

### Правила, которые соблюдает бот
- Комиссия с продавца (15% за абонемент, 30% за промокод; ставка, на которую согласился продавец, сохраняется в объявлении) — только после закрытия сделки, от фактической цены. Покупатель комиссию не платит.
- Сделку нельзя закрыть, пока продавец не подтвердил итоговую цену.
- Одно объявление нельзя продать дважды, комиссию нельзя отметить полученной дважды
  (проверяется и в коде, и уникальными ограничениями базы).
- Одна активная заявка покупателя на объявление; своё объявление купить нельзя; заявка не резервирует автоматически.
- В каталоге нет проданных, снятых, зарезервированных, просроченных и неодобренных объявлений.
- Личные данные (имя, телефон, Telegram, скриншоты) видит только администратор. В описании бот не пропускает
  телефоны, @username и ссылки; администратор дополнительно проверяет описание перед публикацией.
- Бот никогда не спрашивает пароли и коды 1Fit. Работает только в личных сообщениях.

### Рекомендуемая цена и цены 1Fit
- На шаге «Цена» (в боте и в мини-аппе) продавец видит **рекомендуемую цену** и кнопку «Поставить». Расчёт:
  берётся самый короткий тариф 1Fit, который покрывает оставшиеся дни (3, 6, 12 или 24 мес.), его цена
  пересчитывается на эти дни, минус 30%. Если абонемент в рассрочке, оставшиеся платежи, которые покупатель
  внесёт сам, вычитаются из цены. Код — `two_fit/pricing.py` (там же скидка и пределы).
- Дороже 85% от цены 1Fit поставить нельзя — бот объясняет, что у 1Fit выйдет выгоднее; намного дешевле
  (меньше 40%) — можно, но бот предупреждает об ошибке.
- В карточке объявления покупатель видит «≈ 459 000 сум/мес · у 1Fit 658 000 (−30%)».
- **Наблюдатель цен 1Fit** 5 раз в день (`FIT_WATCH_TIMES`, по Ташкенту) читает цены из API 1Fit
  (`FIT_API_URL`, Ташкент) и сравнивает с ценами бота. Если они изменились — администраторам приходит
  сообщение с кнопками «Обновить цены в боте» / «Оставить как есть». Сами цены не меняются: ошибка чтения
  не должна превратиться в странные рекомендации. Если 1Fit не отвечает 2 проверки подряд — одно
  предупреждение в день. Команда `/prices` (и кнопка «💹 Цены 1Fit» в `/admin`) показывает текущие цены,
  последнюю проверку и позволяет проверить сейчас. Выключить — `FIT_WATCH=0`.

## Запуск

Нужен Python 3.11+.

```bash
git clone https://github.com/SultonbekovSarvarbek/two-fit.git
cd two-fit
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # и заполните BOT_TOKEN и ADMIN_IDS
python -m two_fit
```

Данные хранятся в `data/two_fit.db` (SQLite) и сохраняются после перезапуска — включая незаконченные
шаги анкеты. Для постоянной работы запустите бота как службу (systemd, Docker, PM2 и т. п.)
и делайте резервную копию `data/`.

## Что настроить

1. **Токен** — создайте бота в @BotFather, вставьте токен в `.env` → `BOT_TOKEN`.
2. **Администраторы** — запустите бота, отправьте ему `/id`, впишите полученные ID через запятую
   в `ADMIN_IDS`, перезапустите.
3. **Контакт поддержки** — `SUPPORT_USERNAME` в `.env` (сейчас `s_sarvar`). Меняется в одном месте для всего бота.
4. **Картинки** — см. [`assets/README.md`](assets/README.md): приветствие 640×360 и логотип.
5. **Описание в BotFather** (по желанию): `/setdescription` и `/setabouttext` — можно взять
   текст приветствия из `two_fit/locales/*.json` → `welcome`.

## Мини-апп

Мини-апп — это страница, которую отдаёт сам бот (отдельно ничего запускать и собирать не нужно).
Telegram открывает мини-аппы только по **HTTPS**, поэтому нужен публичный адрес:

1. Направьте HTTPS-адрес на порт бота (`WEBAPP_PORT`, по умолчанию 8080): через nginx / Caddy на сервере
   или, для пробы, через туннель — например `cloudflared tunnel --url http://localhost:8080`.
2. Впишите адрес в `.env` → `WEBAPP_URL=https://ваш-адрес/` и перезапустите бота.

После этого слева от поля ввода появится кнопка **Two Fit**, а в чате вместо клавиатуры с разделами
останется одна кнопка «Открыть приложение» (её же присылает `/app`). Админка `/admin` работает как раньше.
Чтобы выключить мини-апп, очистите `WEBAPP_URL` и перезапустите бота.

- Вход — по подписи Telegram (`initData`): пароли не нужны, чужие объявления и контакты не видны.
- Скриншот абонемента, прикреплённый в мини-аппе, бот присылает продавцу в чат — так он попадает к администратору.
- Тексты мини-аппа — ключи `app.*` в тех же файлах `two_fit/locales/*.json`.
- Код: `two_fit/webapp/server.py` (API) и `two_fit/webapp/static/index.html` (страница).

## Как править тексты

Все тексты — в двух файлах: `two_fit/locales/ru.json` и `two_fit/locales/uz.json`
(узбекский — кириллица). Меняйте только значения справа, ключи и `{подстановки}` оставляйте.
После правки запустите тесты — они проверят, что в обоих языках одинаковые ключи и подстановки.
Список городов — `CITIES` в `two_fit/i18n.py` и ключи `city.*` в файлах текстов.

## Тесты

```bash
pip install -r requirements-dev.txt
pytest
```

122 теста без реального токена: расчёт комиссии, проверки ввода, все статусы и запреты,
двойная продажа и двойная комиссия (в том числе одновременные нажатия), сквозной сценарий
через настоящие обработчики (продавец на узбекском, покупатель и админ на русском),
мини-апп (подпись Telegram, проверки формы, заявки, чужие объявления), скрытие личных данных, закрытый доступ к админке, сохранение данных и анкеты после перезапуска.

## Структура

```
two_fit/
  __main__.py        запуск: python -m two_fit
  app.py             сборка бота и диспетчера
  config.py          настройки из .env
  repo.py            база SQLite и все бизнес-правила
  money.py           расчёт комиссии
  validators.py      проверка ввода (даты, цены, телефоны, контакты в тексте)
  i18n.py, locales/  тексты RU / UZ
  storage.py         хранение шагов анкет в SQLite
  bot/handlers/      каталог, продажа, мои объявления, покупка, админка
  webapp/            мини-апп: API (server.py) и страница (static/index.html)
tests/               тесты
assets/              картинки
```

## Пока не входит

Онлайн-оплата, автоматическая передача абонементов, интеграция с 1Fit, чат покупатель–продавец,
встроенный чат поддержки, платное продвижение, автоматическая проверка оплаты.
